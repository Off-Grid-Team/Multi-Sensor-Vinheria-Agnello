</p>

---

### 📋 Descrição do Projeto

Este projeto consiste em um sistema completo de monitoramento ambiental utilizando sensores **LDR** (luminosidade) e **DHT11** (temperatura e umidade) conectados a um **Arduino Uno**. O sistema lê continuamente os parâmetros climáticos do ambiente da vinheria, exibe dados em tempo real em um **Display LCD 16x2** e aciona um conjunto de LEDs coloridos e um buzzer para alertar sobre condições que possam comprometer a conservação dos vinhos
